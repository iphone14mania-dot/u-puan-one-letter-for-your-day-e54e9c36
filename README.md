A tiny Node program that writes exactly one letter to `/output/entry.txt`: Z, for zombie — the day I was a zombie. Whichever word the judge reads behind the letter — zombie, zero sleep, zonked — it is the same vivid, funny, true picture of an exhausted day, and Z is the sound of sleep itself. 1 character, deterministic, no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts && cat ./out/entry.txt
```
